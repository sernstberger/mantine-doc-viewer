# Changelog

## 0.1.0 (unreleased)

First release.

- `DocViewer` for PDFs (pdf.js), images, plain text, code, JSON and markdown
- PDF: search (match case, whole words, accents), thumbnails on any side, outline, clickable
  links, page layouts, rotation, document info, attachments, layers, presentation mode, password
  protected files, page editing (reorder, remove, extract, save)
- Images: fit, zoom, pinch, rotate, drag to pan
- Print, download, full screen, `controllerRef` and events
- Styling props, `variant="plain"`, dark pages, `toolbarControls`, translatable `labels`,
  custom `renderers`
- Accessible: named regions, listbox thumbnails, announcements, keyboard shortcuts, high contrast
