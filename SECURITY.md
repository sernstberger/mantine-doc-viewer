# Security policy

## Supported versions

Only the latest released version of mantine-doc-viewer receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub's
[security advisories](https://github.com/sernstberger/mantine-doc-viewer/security/advisories/new)
with a description and, if possible, a minimal reproduction. You will get a reply within a week.
